  in backups outside the workspace and is not part of the distribution.

## 5. Clean-room workspace creator

`tools/create_game_workspace.py` copies skills, roles, references, tests,
helpers, and legal files, then generates an engine-neutral `project.yaml`,
English-first `START_HERE.md`, and a per-file SHA-256 manifest. It rejects an
existing target, source-inside/source-ancestor targets, and symlink/junction
paths. It never initializes Git, configures a remote, installs global skills,
starts a Codex thread, or deletes a destination. The default mode is dry-run.

```text
python -m unittest tests.test_game_workspace -v
EXIT: 0
RESULT: Ran 13 tests — OK

python tools/create_game_workspace.py --output <new-path>
EXIT: 0
RESULT: PLAN: clean Codex game workspace (dry-run; no files written)

python tools/create_game_workspace.py --verify <created-path>
EXIT: 0
RESULT: VERIFY: PASS — manifest hashes and clean-template inventory match <created-path>

# Run from the new workspace root
python tools/codex-studio/orchestrate.py --once --text
EXIT: 0
RESULT: state=needs_engine; skill=$codex-setup-engine
```

These commands prove workspace isolation and file integrity only. `START_HERE.md`
requires the new window to save Skill selectors, approvals, delegation, input
hashes, diffs, checkpoints, and command output under that game's
`production/provenance/`. Without a host transcript, the run must be marked
`NOT ASSESSED`; file shape is not Skill invocation evidence.

## 6. Non-forging provenance receipt helper

`tools/codex-studio/provenance_receipt.py` creates only a `NOT ASSESSED`
`receipt.json` / `receipt.md` shell, records declared input SHA-256 values, and
strictly checks host-copied transcript, diff, checkpoints, and command exit
codes. It never generates a transcript or upgrades a receipt to `VERIFIED`.

```text
python -m unittest tests.test_provenance_receipt -q
EXIT: 0
RESULT: Ran 5 tests — OK
```

The five regression cases cover missing initial evidence, path traversal,
synthetic summary transcripts, missing Skill hashes, and a complete host-export
fixture. The full workspace suite includes this CLI (113 tests).

## 7. Honest boundary

This repository verifies the Codex Game Studios skills, roles, references,
dispatcher, workspace creator, packager, and provenance tools. It does not
claim an engine, game design, playable build, screenshots, payments, online
services, or store integration. Open the generated game workspace in a new
Codex window, run `$codex-start`, and follow
`docs/codex-studio/clean-room-workflow.md` while retaining the required
evidence.
